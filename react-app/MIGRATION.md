# Streamlit → React + Vite 마이그레이션 기록

## 기능 비교

| 영역 | 기존 Streamlit | React + Vite |
|---|---|---|
| 실행 환경 | Python 서버 필요 | GitHub Pages에서 정적 실행 |
| 페이지 이동 | Streamlit 멀티페이지 | 해시 기반 클라이언트 내비게이션 |
| 상태 관리 | `st.session_state` | React state + `localStorage` |
| 전기 기구 입력 | 행 추가·삭제, 유효 행 저장 | 동일 기능, 태블릿용 반응형 입력 카드 |
| 제품별 그래프 | Plotly 막대그래프 | 접근 가능한 반응형 SVG 막대그래프 |
| 순차 학습 | `st.stop()`과 조건부 렌더링 | 단계 완료 상태에 따른 잠금 해제 |
| 주전자 데이터 | CSV + Plotly | 같은 50개 데이터 + 분포·산점도·원본 표 |
| 주전자 실험 | 물의 양별 시간 계산 | 동일 계산식과 정답 판정 유지 |
| 에너지 다이어트 | 입력 변경마다 Python 재실행 | 브라우저에서 즉시 재계산 |
| 결과 저장 | PDF 생성 함수만 존재, 다운로드 버튼 없음 | 인쇄 전용 A4 학습지와 PDF 저장 제공 |
| 배포 | Streamlit Community Cloud | GitHub Actions + GitHub Pages |

## 유지한 계산 기준

- 주전자 A: `(물의 양 / 100) × 18 + 6초`
- 주전자 B: `(물의 양 / 100) × 19 + 7초`
- 주전자 C: `(물의 양 / 100) × 18 + 6초`
- 탄소 배출계수: `0.478 kgCO₂/kWh`
- 평균 전력 단가: `200원/kWh`
- 소나무 연간 흡수량: `6.6 kgCO₂`
- 에어컨 기본 소비전력: `1,800W`
- PC/TV: `150W`, 드라이어: `1,600W`
- 냉장고 열유입 및 등급별 기준값, 대기전력 값도 원본과 동일

## 명확히 표시한 원본 가정

- 원본은 에어컨 Before 소비량에 실외·설정 온도차를 직접 반영하지 않고, After에서 설정 온도 1°C 상승당 7% 감소를 적용합니다.
- “자는 동안 차단”이라는 기존 문구와 달리 계산은 선택한 기기의 24시간 대기전력을 전부 제거합니다. 새 화면에서는 이 계산 가정을 명시했습니다.
- 계산 결과는 수업용 단순 모형이며 실제 전기요금이나 제품 성능을 보장하지 않습니다.

## 원본에서 확인되지 않은 기능

README에는 `2차시-1: 소비전력만 보고 판단할 수 있을까?`가 언급되지만 해당 소스 파일은 제공된 프로젝트에 없습니다. 임의로 내용을 만들지 않고, 확인 가능한 1차시 활동과 2차시 에너지 다이어트를 이식했습니다.

## UI/UX 개선

- 터치하기 쉬운 44px 이상의 주요 조작 영역
- 태블릿과 휴대전화에서 카드형으로 재배치되는 반응형 화면
- 현재 단계와 완료 여부를 보여 주는 단계 표시
- 잠긴 활동의 해제 조건 안내
- 색상에만 의존하지 않는 수치·텍스트 피드백
- 키보드 포커스, 차트 대체 설명, 폼 레이블 제공
- 학생 입력값 자동 저장과 전체 초기화 기능

## 웹 전용 상호작용 개선

- 처음 사용하는 학생도 바로 조작해 볼 수 있는 연습 데이터 자동 입력
- 1차시 활동 여정을 보여 주는 진행 표시
- 산점도의 데이터 점을 터치해 개별 제품 수치를 확인하는 탐색 기능
- 물의 양에 따라 A·B·C 주전자가 경쟁하는 가열 애니메이션
- 소비전력뿐 아니라 `소비전력 × 끓는 시간`으로 계산한 1회 사용 에너지 비교
- 가볍게·균형 있게·도전하기 에너지 절약 목표 프리셋
- Before 대비 남은 사용량을 즉시 보여 주는 원형 게이지
- 냉장고·에어컨·PC/TV·드라이어·대기전력별 절감 기여도 시각화
